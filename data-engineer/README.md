\# Data Engineering



Esta sección contiene proyectos orientados al desarrollo de soluciones de \*\*Data Engineering\*\*, desde la extracción y transformación de datos hasta su almacenamiento y preparación para análisis.



Los proyectos buscan representar escenarios prácticos mediante el uso de Python, SQL, APIs, bases de datos, Docker y servicios cloud.



\## 📂 Proyectos



\### 01 - Credit Card Fraud Pipeline



Pipeline ETL para el procesamiento de datos de transacciones y generación de información analítica relacionada con fraude.



\*\*Tecnologías:\*\*



\- Python

\- Pandas

\- SQL

\- SQLite

\- Docker



\---



\### 02 - BNPL Data Pipeline



Pipeline ETL basado en un escenario de Buy Now, Pay Later (BNPL), incorporando procesos de limpieza, validación, transformación y consultas analíticas.



\*\*Tecnologías:\*\*



\- Python

\- Pandas

\- SQL

\- SQLite

\- Docker



\---



\### 03 - Fintech Data Experience Agent



Pipeline de datos orientado a un escenario fintech. Incluye procesos de transformación, almacenamiento y consultas analíticas, además de una aplicación de agente conectada a los datos.



\*\*Tecnologías:\*\*



\- Python

\- Pandas

\- SQL

\- SQLite

\- Docker

\- Gemini API



\---



\### 04 - Real-Time Public API Data Pipeline



Pipeline para extraer datos desde una API pública, transformar la información y cargarla en PostgreSQL/Supabase para posteriormente utilizarla en procesos de análisis y visualización.



\*\*Tecnologías:\*\*



\- Python

\- Pandas

\- REST API

\- PostgreSQL

\- Supabase

\- Power BI

\- Docker
