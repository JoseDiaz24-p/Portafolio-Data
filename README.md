\# Portafolio de Data Engineering



Portafolio personal enfocado en el desarrollo de soluciones de \*\*Data Engineering\*\*, con proyectos prácticos orientados a la extracción, transformación, validación, almacenamiento y procesamiento de datos.



Actualmente estoy construyendo y ampliando este portafolio mediante proyectos basados en datos reales, APIs públicas y datasets abiertos, con el objetivo de desarrollar experiencia práctica en procesos de datos similares a los utilizados en entornos profesionales.

\## 🚀 Proyectos



\### 01 - Credit Card Fraud Pipeline



Pipeline ETL orientado al procesamiento y análisis de transacciones con información relacionada con fraude.



\*\*Tecnologías:\*\* Python, Pandas, SQL, SQLite, Docker.



\### 02 - BNPL Data Pipeline



Pipeline de procesamiento de datos para un escenario de Buy Now, Pay Later (BNPL), incorporando validaciones de calidad, transformación y análisis mediante SQL.



\*\*Tecnologías:\*\* Python, Pandas, SQL, SQLite, Docker.



\### 03 - Fintech Data Experience Agent



Pipeline de datos para un escenario fintech, incorporando transformación de datos, consultas analíticas y una capa de interacción mediante un agente conectado a una base de datos.



\*\*Tecnologías:\*\* Python, Pandas, SQL, SQLite, Docker, Gemini API.



\### 04 - Real-Time Public API Data Pipeline



Pipeline orientado a la extracción periódica de información desde una API pública, transformación de los datos y carga en PostgreSQL/Supabase para su posterior análisis y visualización.



\*\*Tecnologías:\*\* Python, Pandas, APIs REST, PostgreSQL, Supabase, Power BI, Docker.
